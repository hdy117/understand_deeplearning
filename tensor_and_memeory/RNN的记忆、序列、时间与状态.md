# RNN 的记忆、序列、时间与状态

> 核心：**RNN 一边读取序列，一边不断更新内部状态。过去的信息通过旧状态参与当前计算，因此网络表现出了记忆。**

## 1. 一句话理解 RNN

RNN 每一步都在做一件事：

\[
\boxed{\text{旧状态}+\text{当前输入}\rightarrow\text{新状态}}
\]

数学形式是：

\[
h_t=f(h_{t-1},x_t)
\]

其中：

- \(x_t\)：当前时间步的输入，例如当前词；
- \(h_{t-1}\)：上一时间步的内部状态；
- \(h_t\)：结合当前输入与过去状态后形成的新状态；
- \(f\)：RNN 的状态更新函数。

暂时不需要理解 \(f\) 内部的全部计算，先理解“状态如何随序列不断更新”即可。

## 2. 用“我 吃 苹果”走一遍

假设 RNN 每次只读一个词：

```text
时间 t=1          t=2          t=3
       │            │            │
输入：  我     →     吃     →     苹果
       │            │            │
状态： h₀ → h₁  →   h₁ → h₂  →   h₂ → h₃
```

### 第一步：读到“我”

\[
h_1=f(h_0,\text{“我”})
\]

网络从初始状态 \(h_0\) 变成 \(h_1\)。

可以暂时把 \(h_1\) 想象成：

```text
“目前句子的主语可能是‘我’。”
```

真实网络里不是这句人类可读的话，而是一串数字，也就是一个向量。

### 第二步：读到“吃”

\[
h_2=f(h_1,\text{“吃”})
\]

此时网络不是只处理孤立的“吃”，而是同时利用：

```text
当前输入：吃
之前状态：前面出现了“我”
```

新状态可能相当于：

```text
“目前理解到：我在进行吃东西这件事。”
```

### 第三步：读到“苹果”

\[
h_3=f(h_2,\text{“苹果”})
\]

网络结合：

```text
当前输入：苹果
之前状态：前面是“我吃……”
```

于是形成对“我吃苹果”的整体内部表示。

这就是 RNN 的核心：**每一步都不是从头理解当前输入，而是在此前状态的基础上继续更新。**

## 3. 记忆在哪里？

记忆主要体现在 \(h_1、h_2、h_3\) 这些状态中。

读到“苹果”时，当前输入本身只有：

```text
苹果
```

但网络还能结合前面的“我吃”，因为 \(h_2\) 已经携带了相关信息：

```text
                 过去的信息
             ┌────────────────┐
             ▼                │
“我” → h₁ → “吃” → h₂ → “苹果” → h₃
                         ▲
                      当前输入
```

因此：

> **记忆不一定是把“我吃”原样保存下来，也可以是把“我吃”对后续理解有用的影响保存在状态中。**

这是一种**压缩的记忆**。

就像读完一本书后，我们通常不会记住每一页原文，但会保留对人物、剧情和伏笔的理解。读到新情节时，这些保留下来的理解仍会影响我们。

## 4. 状态是什么？

**状态就是网络处理到当前这一步时，对目前情况形成的内部表示。**

用一个刻意简化的例子说明。假设状态只有两个数字：

\[
h_t=
\begin{bmatrix}
\text{前文与“吃”有关的程度}\\
\text{前文与“手机”有关的程度}
\end{bmatrix}
\]

真实网络不会人工规定这两个维度，这里只是为了直观理解。

### 读到“我吃……”

```text
h₂ ≈ [0.9, 0.1]
```

表示当前语境更像是“吃东西”。

### 读到“我用……”

```text
h₂ ≈ [0.1, 0.9]
```

表示当前语境更像是“使用设备”。

即使下一步输入都是“苹果”，两种历史也会产生不同的新状态：

\[
h_{\text{吃苹果}}=f([0.9,0.1],\text{苹果})
\]

\[
h_{\text{用苹果}}=f([0.1,0.9],\text{苹果})
\]

```text
我吃 → 苹果 → 更偏向“水果”
我用 → 苹果 → 更偏向“品牌/设备”
```

因此：

\[
\boxed{\text{当前输入相同，不代表当前状态相同。}}
\]

因为历史不同，\(h_{t-1}\) 就不同。

## 5. 时间在哪里？

时间首先体现在：**输入按照先后顺序到达，并依次改变状态。**

例如，“我吃苹果”和“苹果吃我”使用了相同的词，但顺序不同：

```text
顺序一：
我 → 吃 → 苹果
h₀ → h₁ → h₂ → h₃

顺序二：
苹果 → 吃 → 我
h₀ → h₁' → h₂' → h₃'
```

最终状态通常不同：

\[
h_3\neq h_3'
\]

所以，“隐式表示时间”可以先简单理解为：

> **模型不一定需要单独保存“这是第几个词”，但输入的先后顺序会通过状态更新过程留下影响。**

## 6. 把四个概念连起来

```text
序列：我 → 吃 → 苹果
       │    │     │
       ▼    ▼     ▼
时间：先到  后到  最后到
       │    │     │
       ▼    ▼     ▼
状态：h₁ → h₂ →  h₃
       └────┴─────┘
          状态传递
             │
             ▼
记忆：过去对当前状态仍有影响
```

- **序列（sequence）**：输入按先后次序到来。
- **时间（time）**：不同时间到达的输入依次改变计算过程。
- **状态（state）**：网络在当前时间步形成的内部表示。
- **记忆（memory）**：过去的信息通过旧状态参与当前计算。

## 7. 用读悬疑小说来类比

读小说时，我们通常会：

```text
读到新句子
     +
脑子里此前对剧情的理解
     ↓
形成新的理解
     ↓
带着新理解继续读下一句
```

我们不会每读一页都从头开始，也不一定记住此前每个字；我们会带着不断更新的“剧情状态”继续阅读。

RNN 也是：

```text
当前输入 xₜ
     +
之前的状态 hₜ₋₁
     ↓
新的状态 hₜ
     ↓
继续处理下一个输入
```

因此，所谓记忆，不一定是把过去完整存起来；也可以是：

> **过去已经改变了系统现在的状态，而这个状态继续影响系统接下来的处理。**

## 8. 与多层 RNN 的输出形状联系起来

对于输入：

\[
X\in\mathbb{R}^{B\times T\times d_{\text{model}}}
\]

每一层 RNN 都沿时间维处理 \(T\) 个输入，并为每个时间步产生一个状态。

把所有时间步的状态堆叠起来，得到：

\[
H=[h_1,h_2,\ldots,h_T]
\]

其形状通常为：

\[
\boxed{[B,T,\text{hidden\_size}]}
\]

下一层 RNN 会把上一层的整个输出序列作为自己的输入。最后一层的输出通常仍然保留时间维。

只有当：

\[
\text{hidden\_size}=d_{\text{model}}
\]

时，输出形状才是：

\[
\boxed{[B,T,d_{\text{model}}]}
\]

## 9. 最终总结

RNN 的基本循环是：

\[
\boxed{h_t=f(h_{t-1},x_t)}
\]

最重要的理解是：

1. 当前输入会更新状态；
2. 旧状态携带着过去对当前有用的信息；
3. 因此，当前输出不仅由当前输入决定，也受历史影响；
4. 状态不是历史的完整副本，而是面向任务形成的压缩表示；
5. 多层 RNN 会把每个时间步的状态继续传给下一层处理。

一句话收尾：

> **RNN 的记忆，不在处理过程之外；记忆就是过去通过状态更新，持续参与当前处理。**
