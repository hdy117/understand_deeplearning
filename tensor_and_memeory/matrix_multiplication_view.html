矩阵乘法 的六副眼镜 Six Lenses on Matrix Multiplication — 一个定义，六种看法

( m × r )·( r × n )⟶( m × n )

中间的 r 是咬合的齿轮：所有视角的分歧，归根结底都是"这个求和轴该怎么切"。往下滚，每副眼镜都配一个可以动手玩的演示。

01Row × Column · 点积视角

最经典的一副眼镜：C 的第 (i, j) 格 = A 的第 i 行 · B 的第 j 列。整幅矩阵就是一张 m×n 的"相似度记分表"——Transformer 里的 attention score（QKT）就是这么来的。

cij = ai1·b1j + ai2·b2j + ⋯ + air·brj = row i of A · col j of B
playground — 点（或按 Tab 移到）C 的任意一格
A 的第 i 行（橙色） B 的第 j 列（蓝色） C 的 (i,j) 格（粉色）
提示：每一格都是一次独立的 dot product

02Column View · 列视角

换个大一点的单位——整列。C 的第 j 列 = A 乘 B 的第 j 列。再展开一层：它是 A 各列的线性组合，配方写在 B 的第 j 列里。A 的列是原料库，B 的列是配方单。

C:j = A·B:j = b1j·a:1 + b2j·a:2 + ⋯ + brj·a:r
playground — 拖动滑块选择列 j，看 C 的一整列如何由 A 的列混出来
B 的第 j 列 = 配方 C 的第 j 列 = 成品
j = 1

03Row View · 行视角

完全对偶的另一半：C 的第 i 行 = B 各行的线性组合，配方写在 A 的第 i 行里。列视角里 B 出系数、A 出原料；行视角里角色互换。同一次乘法，向左看和向右看各讲一个 mixing 的故事。

Ci: = Ai:·B = ai1·b1: + ai2·b2: + ⋯ + air·br:
playground — 拖动滑块选择行 i，看 C 的一整行如何由 B 的行混出来
A 的第 i 行 = 配方 C 的第 i 行 = 成品
i = 2

04Outer Products · 外积累加

现在把求和轴 k 竖切：A 的第 k 列（列向量）乘 B 的第 k 行（行向量），得到一整块 rank-1 的"地毯"；r 块地毯叠起来就是 C。点积视角是"先定位再求和"，外积视角是"先整块再累加"。

这把刀是理解低秩（low-rank）的钥匙，也直通序列模型里的记忆写入：DeltaNet 的 delta rule 每一步对记忆矩阵做的，正是一次 rank-1 update。
C = Σk=1..r a:k·bk:T　（每一块 a:kbk:T 都是 rank-1 矩阵）
playground — 按下播放，看 rank-1 地毯一块一块把 C 叠出来
A 的第 k 列 B 的第 k 行 正在叠加的 rank-1 地毯
k = 0 / 3

05Composition · 映射复合

前四副眼镜回答"怎么算"，这一副回答"为什么这么定义"。矩阵是线性映射的化身：如果你要求乘积矩阵恰好实现"先做 B 再做 A"的复合，那么逐列推导会被迫得到 cij=Σkaikbkj——这是唯一满足 composition law 的乘法。维度链必须咬合、结合律天然成立，都从这里来。

(AB)x = A(Bx)　——　矩阵即映射，乘即接力
playground — 用滑块调输入向量 x，两条路径实时对比
x₁ 1
x₂ 0
x₃ -2

06Brackets · 括号经济学

结合律保证 (AB)C = A(BC) 的值不变，但账单天差地别。Attention 就是分水岭：标准 self-attention 走 (QKT)V，先造 n×n 大矩阵；Linear Attention 走 Q(KTV)，先压成 d×d 小矩阵——同一个输出，复杂度从 O(n²d) 掉到 O(nd²)。

括号视角的精神：矩阵乘法的"值"由结合律保证不变，"计算图"由你自由选择——这个自由度在 GPU 时代值真金白银。
path 1: (QKT)V ≈ n²d 次乘加　　vs　　path 2: Q(KTV) ≈ nd² 次乘加
playground — 拖滑块调序列长度 n 与维度 d，看两张账单的差距
n = 2^4096
d = 2^128
(QKT)V · O(n²d)
Q(KTV) · O(nd²)
attention 矩阵显存（n², fp32）

07Exercises · 练一练

六道题，一副眼镜一道。先盖住答案自己算，再点开核对。练 2、3、4 用的是同一组矩阵——它们的答案会互相印证，这正是"四副眼镜看同一场乘法"的意思。练 6 可以直接回到 06 的计算器里验证。

练 1 · 点积视角

给定下面的 A 与 B，只算两格：c12 和 c21。

×
答案与解析

c12 = A 第 1 行 · B 第 2 列 = (2, 1, 0) · (4, −2, 1)：

c12 = 2·4 + 1·(−2) + 0·1 = 8 − 2 + 0 = 6

c21 = A 第 2 行 · B 第 1 列 = (−1, 3, 2) · (1, 0, 3)：

c21 = (−1)·1 + 3·0 + 2·3 = −1 + 0 + 6 = 5

要点：每一格都是一次独立的 dot product——算一格不需要知道其他格。

练 2 · 列视角

给定 A (3×2) 与 B (2×3)，不要逐格算：把 C 的第 2 列写成 A 各列的线性组合，再算出来。

×
答案与解析

配方在 B 的第 2 列：B:2 = (1, 3)T，所以 C:2 = 1·a:1 + 3·a:2：

C:2 = 1·(1, 0, 3)T + 3·(2, 1, 0)T = (1+6, 0+3, 3+0)T = (7, 3, 3)T

要点：C 的第 j 列 = A 的列按"B 第 j 列的配方"混合。这题只用 A 的列和 B 的一列，B 其余两列根本没出场。

练 3 · 行视角

同一组 A、B（见练 2）。这次用行视角：把 C 的第 3 行写成 B 各行的线性组合，并算出来。

答案与解析

配方在 A 的第 3 行：A3: = (3, 0)，所以 C3: = 3·b1: + 0·b2:：

C3: = 3·(2, 1, 0) + 0·(−1, 3, 2) = (6, 3, 0)

要点：与练 2 对偶——角色互换，A 出系数、B 出原料。注意 C3:2 = 3，和练 2 算出的 C:2 第 3 个分量完全一致：两种切法在同一个格子上会师。

练 4 · 外积视角

还是同一组 A、B。把 C 写成 r = 2 块 rank-1 地毯之和：分别算出 a:1b1:T 与 a:2b2:T，再相加得到完整的 C。

答案与解析

第一块地毯：a:1 = (1, 0, 3)T，b1: = (2, 1, 0)：

第二块地毯：a:2 = (2, 1, 0)T，b2: = (−1, 3, 2)：

两块叠加：

C = [[0, 7, 4], [−1, 3, 2], [6, 3, 0]]

印证时刻：C 的第 2 列 (7, 3, 3) 正是练 2 的答案，第 3 行 (6, 3, 0) 正是练 3 的答案——同一场乘法，三种切法，零矛盾。另外注意两块地毯各自都是 rank-1（每一行都是同一行的倍数）。

练 5 · 复合视角

在 R² 上：B = 向 x 轴的投影 [[1,0],[0,0]]，A = 逆时针旋转 90° [[0,−1],[1,0]]。求 C = AB，并用"先投影再旋转"描述它对任意向量 (x, y) 的作用。再算 BA，说明乘法为什么不交换。

答案与解析
C = AB = [[0, 0], [1, 0]]

分两步看 (x, y)：先 B 投影得 (x, 0)，再 A 旋转 90° 得 (0, x)——乘积矩阵一步到位：C(x, y) = (0, x)。

反过来：BA = [[0,−1],[0,0]]，它把 (x, y) 映到 (−y, 0)：先旋转再投影。

要点：AB ≠ BA，因为"先投影再旋转"和"先旋转再投影"本来就是两个不同的映射。矩阵乘法不交换，根子在函数复合不交换——这正是复合视角的力量。

练 6 · 括号经济学

Attention 里 n = 8192，d = 128（Q, K, V ∈ Rn×d）。分别估算 (QKT)V 与 Q(KTV) 的乘加次数（MACs，按 n²d 与 nd² 计），哪条路径便宜、便宜多少倍？再算一下 n×n attention 矩阵（fp32）要占多少显存。

答案与解析

path 1 = n²d = 8192² × 128 ≈ 8.59 G MACs；path 2 = nd² = 8192 × 128² ≈ 134.2 M MACs。

比值恰好是 n / d = 8192 / 128 = 64——path 2 便宜 64 倍，而且序列越长优势越大。

显存：8192² × 4 B ≈ 268.4 MB（256 MiB）——这还只是一个 head 一层。

要点：结合律保证结果相同，括号决定账单。回到页面 06 的计算器，把 n 拨到 8192、d 拨到 128，可以直接核对这些数字。

挑战 · 六副眼镜合起来

开放思考：Linear Attention 选择 Q(KTV) 括号后，可以定义 S = KTV（d×d）。请用外积视角写出 S 的逐 token 累加形式，并解释：为什么这让"边读序列边更新一块固定大小的记忆"成为可能？它和我们聊过的 DeltaNet rank-1 update 有什么神似之处？

参考思路（此题无唯一答案）

按 token 把 K、V 的行取出来：S = KTV = Σt ktT vt——每个 token 贡献一块 d×d 的 rank-1 地毯。

于是推理/训练可以写成 recurrence：St = St−1 + ktTvt，ot = qt St。记忆大小恒为 d×d，与序列长度无关——这就是 Linear Attention 能翻译成 RNN 形式的原因。

与 DeltaNet 的神似：DeltaNet 同样维护一块矩阵记忆，同样每步 rank-1 写入，只是写入规则从"无脑累加"升级为 delta rule——先按旧记忆读出当前预测、只写入误差部分（写入/擦除更讲究）。

要点：括号视角给了便宜的计算顺序，外积视角给了递推的记忆解释——两副眼镜叠着戴，Linear Attention 的全貌就出来了。
