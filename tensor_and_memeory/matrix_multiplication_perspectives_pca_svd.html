矩阵乘法的几副眼镜 从 AT 到 PCA 与 SVD A teaching path through transpose, Gram, SVD and PCA

AT⟶ATA⟶xTMx⟶UΣVT⟶PCA

先把同一个乘法从 dot product、row、column、outer product、composition、geometry 六个方向走一遍，再看 transpose 如何长出 Gram matrix、quadratic form、SVD 和 PCA。每个大桥都配手算例子或可动手玩的演示。

00先把同一个乘法走六遍：shape 是护栏，语义是方向盘

这一节只做一件事：把 A B 这三个字符拆成六种互补的读法。先看数字怎样对接，再看 rows、columns、rank-1 小块和 linear map 怎样接上。

取两个小矩阵：

A = [ 1 2 ; 3 4 ]　　B = [ 5 6 ; 7 8 ]　　C = AB = [ 19 22 ; 43 50 ]

第一步：dot product。 C11 = 1×5 + 2×7 = 19。一个 output cell，就是 A 的一行和 B 的一列做一次 dot product。

第二步：row recipe。 A 的第一行是 (1, 2)，所以 C 的第一行是 1×B 的第一行加上 2×B 的第二行：

C1: = 1 [ 5 6 ] + 2 [ 7 8 ] = [ 19 22 ]

第三步：column mixture。 B 的第一列是 (5, 7)T，所以 C 的第一列是 5×A 的第一列加上 7×A 的第二列：

C:1 = 5 [ 1 ; 3 ] + 7 [ 2 ; 4 ] = [ 19 ; 43 ]

第四步：outer product。 固定共同索引 k，一层一层叠 rank-1 地毯：

AB = A:1B1: + A:2B2:

第五步：composition。 对向量 x 而言，(AB)x = A(Bx)：最右边的 B 先把输入改写一次，A 再接手。

第六步：geometry。 矩阵不是一张冷冰冰的数字表，而是一个 map。它可能旋转、拉伸、压扁、翻转，甚至把平面压成一条线；SVD 会把这些动作分开。

小结：六副眼镜没有六种乘法；它们只是把同一笔账分别解释成“一个格子、一整行、一整列、若干 rank-1 小块、两个 map 的接力和一个几何动作”。

01Transpose · 转置的三层含义

第一层（表面）：行列互换，绕主对角线翻个身——(AT)ij = Aji。这是定义，但几乎没告诉你任何事。

第二层（结构）：行空间与列空间互换身份。A 的列空间变成 AT 的行空间——转置是从"列视角"切换到"行视角"的机械开关。↔ 上篇 02/03 列与行的对偶

第三层（深层，也是真正的定义）：转置是内积结构下的伴随算子（adjoint）——它是唯一能让下面这个恒等式成立的矩阵：

⟨Ax, y⟩ = ⟨x, ATy⟩　⟺　(Ax)Ty = xT(ATy)

读法："转置是把 A 搬到内积另一边时，必须付的代价。" A 本来作用在左边的 x 身上；想把它挪到右边的 y 身上，就得把它换成 AT。凡是有内积的地方（投影、最小二乘、量子力学的厄米共轭），这个恒等式都在背后默默工作。

把“伴随”翻译成人话：“内积结构”只是说，这个空间有一把比较向量的尺子；这里的尺子就是普通 dot product：⟨u,v⟩ = uTv。

于是有两条完全等价的路线：

两条路的 scalar 永远相同。所谓 adjoint，就是“当 A 从 inner product 的左边搬到右边时，保证所有比较结果不变的那个 map”。在普通 Euclidean 坐标下，它恰好写成 transpose。

为什么必然是 transpose？把左边展开：

⟨Ax,y⟩ = Σi(ΣjAijxj)yi = Σjxj(ΣiAijyi) = ⟨x,ATy⟩

括号里按 j 收集的那一坨，正是 (ATy)j。原来按 rows 读的系数，被 transpose 重新按 columns 读回来。

责任回传类比：A 把 input coordinates 混合成 output coordinates；如果 output 方向 y 对结果打了一个分数，ATy 就把这份分数沿原来的连接分配回 input coordinates。neural network 的 backward pass 里，linear layer 的 gradient 反复出现 transpose，就是这条 adjoint 规则在工作。

符号表：A:m×n，x:n，y:m，所以 Ax:m、ATy:n，两边最后都是 scalar。

‖Ax‖² = ⟨Ax,Ax⟩ = ⟨x,ATAx⟩
这就是 ATA 的入口：它在 input space 里记录“经过 A 以后，哪些方向被拉得更长”。后面的 SVD 和 PCA 都会回来读这本账。
复合视角的推论：(AB)T = BTAT——接力的转置 = 倒带，倒带必须反序。先穿袜子再穿鞋，脱的时候得先脱鞋。↔ 上篇 05 复合视角

02Gram Matrix · 列与列的全员相亲表

把点积视角开足马力：G = ATA 的第 (i, j) 格，就是 A 的第 i 列与第 j 列的 dot product。整张表 = A 的列之间的"全员相似度记分表"——对角线是各列的 ‖长度‖²，非对角线是列与列的"夹角余弦 × 长度积"。↔ 上篇 01 点积视角

两个白送的性质，都从定义直接掉出来：

对称：GT = (ATA)T = ATA = G（倒带两次回到原样）。半正定：xTGx = xTATAx = (Ax)T(Ax) = ‖Ax‖² ≥ 0——向量的长度平方永远非负。Gram 矩阵是"对称 + 半正定"最大的天然货源。

Gij = a:iT · a:j　　xTGx = ‖Ax‖² ≥ 0

03Quadratic Form · 碗、鞍与主轴

二次型就是"向量与矩阵再与向量自己点积"：q(x) = xTMx。为什么只研究对称的 M？因为任何方阵 M 的二次型都只由它的对称部分 (M+MT)/2 决定——反对称部分恒贡献零（xTKx = −xTKx ⇒ =0）。所以讨论二次型 = 讨论对称矩阵，而对称矩阵正是 Gram 矩阵的老家。

几何上，q(x) 是一个抛物面状的碗（或鞍）。特征值是碗的"曲率方向表"：全正则碗（正定），全负倒扣（负定），有正有负则鞍（不定）。主轴定理说：对称矩阵总能用特征向量作新坐标轴，把交叉项消掉——碗永远可以"摆正"，摆正的坐标系就是特征向量系。

q(x) = xTMx　→　换到特征向量坐标系后：q = λ₁z₁² + λ₂z₂²　（交叉项消失）

04SVD · 按重要性排序的地毯

奇异值分解 A = UΣVT 有两个同等重要的读法，正好接上上篇两副眼镜：

读法一 · 外积视角：A = Σi σi uiviT——任何矩阵都是 rank-1 地毯之和，而 SVD 把地毯按重要性 σ1 ≥ σ2 ≥ … 排好了序。想近似 A？剪掉 σ 小的地毯就行，这是最优低秩近似（Eckart–Young）。↔ 上篇 04 外积视角

读法二 · 复合视角：A = U Σ VT 把任意线性映射拆成三段接力：先旋转/翻转（VT），再沿坐标轴拉伸（Σ），最后再旋转（U）。单位圆永远被映成椭圆，V 的列给出"输入方向"，σ 给出"拉伸倍数"，U 的列给出"输出方向"。↔ 上篇 05 复合视角

A = VT 旋转 → Σ 拉伸 → U 旋转　　= Σi σi uiviT

05PCA · 把前面全部串起来

现在见证整条链合龙。PCA 的每一步都是前面的老熟人：

① 数据中心化（每列减均值）；② 协方差矩阵 C = XTX/(n−1)——一个 Gram 矩阵（中心化列的全员相亲表，÷(n−1) 而已）；③ 它是对称半正定的，所以它的二次型 xTCx 是一个"数据椭球"；④ 对椭球应用主轴定理：特征向量 = 主成分方向，特征值 = 各方向方差；⑤ 这恰好就是对 X 做 SVD 的右奇异向量。五个概念，一条流水线。

X 中心化 → C = XTX/(n−1) → xTCx 椭球 → 特征分解 → 主成分 = 方差最大的方向

5BPCA 与 SVD 的手算桥：从数据云到主轴

前面的 interactive demo 让你“看见”椭圆和主轴；这一节把同一条路径慢慢算一遍。核心顺序是：先 center，再做 Gram，最后读 eigen-direction。

第一拍：数据先减去均值

把每一行当成一个 sample、每一列当成一个 feature。取三个点 (1, 1)、(2, 2)、(3, 3)，均值是 (2, 2)，因此

Xc = [ −1 −1 ; 0 0 ; 1 1 ]

为什么要 center？因为 PCA 想看的是“围绕中心的变化”，不是数据整体离原点有多远。没有 center，均值会把主轴方向拽偏。

第二拍：covariance 就是一个缩放过的 Gram matrix

C = XcTXc / (N−1) = [ 1 1 ; 1 1 ]

对角线的 1 是两个 feature 各自的 variance；非对角线的 1 是它们一起增减的 covariance。这个例子中两列完全同向，所以 covariance 最大。

第三拍：主成分是一个优化问题

拿单位方向 w 去投影所有 sample，投影后的总平方长度是

‖Xcw‖² = wTXcTXcw = (N−1) wTCw

要让它最大，就解

max‖w‖=1 wTCw　　⇒　　Cw = λw

所以 eigenvector 是主方向，eigenvalue 是沿该方向的 variance。对本例，

w1 = (1,1)T/√2, λ1=2　　；　　w2 = (1,−1)T/√2, λ2=0

数据只沿 diagonal 方向变化。沿 w2 投影全部是零，所以压掉第二轴不会丢掉信息。

SVD 在这里做了什么？

对 centered data 写 SVD：

Xc = UΣVT

再代入 covariance：

C = XcTXc/(N−1) = VΣ2VT/(N−1)

于是 V 的 columns 正好是 PCA directions，σi2/(N−1) 正好是 PCA variances。PCA 从“找最大投影方差”进入，SVD 从“拆开 linear map”进入，最后在 XcTXc 汇合。

为什么是 σ2，不是 σ？

右 singular vector vi 满足 Avi = σiui；再左乘一次 AT：

ATAvi = AT(σiui) = σi2vi

因此 vi 是 ATA 的 eigenvector，eigenvalue 是 σi2。这就是 Gram、eigen-decomposition 和 SVD 之间最关键的一座桥。

最小可运行 PyTorch：同一份 X 同时走 PCA 和 SVD
import torch

# 每行一个 sample，每列一个 feature
X = torch.tensor([
    [1.0, 1.0],
    [2.0, 2.0],
    [3.0, 3.0],
])

# 1) center：按 feature 减均值
Xc = X - X.mean(dim=0, keepdim=True)

# 2) Gram / covariance
C = Xc.T @ Xc / (X.shape[0] - 1)

# 3) covariance 的 eigen-decomposition
eigvals, eigvecs = torch.linalg.eigh(C)
order = torch.argsort(eigvals, descending=True)
eigvals = eigvals[order]
eigvecs = eigvecs[:, order]

# 4) centered data 的 SVD
U, S, Vh = torch.linalg.svd(Xc, full_matrices=False)

print("PCA variances =", eigvals)
print("S^2 / (N-1)  =", S.square() / (X.shape[0] - 1))
print("PCA directions =", eigvecs)
print("SVD directions =", Vh.T)
运行结果怎么对：eigenvectors 与 Vh.T 可能整列差一个负号；这是同一条 axis 的两个朝向，不是数值错误。比较方向时看夹角或绝对值。

Σ收拢：一条依赖链

整篇可以压缩成一句话：转置给了内积的伴随，伴随的自乘给出 Gram 矩阵；Gram 对称半正定，于是二次型有碗可摆；主轴定理（谱定理）把碗摆正，摆正的一般化就是 SVD；把 SVD 应用到数据中心化后的 Gram 矩阵，就得到 PCA。
